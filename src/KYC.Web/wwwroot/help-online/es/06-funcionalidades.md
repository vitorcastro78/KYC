# Funcionalidades por área de negocio

Resumen de las capacidades de la plataforma para el día a día del analista. Para consultar el inventario completo con IDs y base legal, vea la documentación de homologación de su institución.

## Gestión de casos

| Funcionalidad | Dónde en la app |
|----------------|----------------|
| Abrir caso con validación PAC | Nuevo caso |
| Listar y filtrar casos | Casos KYC |
| Aprobar / rechazar / revisión | Detalle del caso |
| Asignación y revisión periódica | Automático después de la aprobación |

## Entidades y UBO

| Funcionalidad | Dónde en la app |
|----------------|----------------|
| Resolución GLEIF / datos societarios | Detalle del caso (tarjeta de empresa) |
| Grafo UBO interactivo | Detalle → Grafo UBO |
| Añadir parte manualmente | Detalle → Añadir parte |
| Informar discrepancia RCBE | Panel de identidad de la parte |

## Cribado y riesgo

| Funcionalidad | Dónde en la app |
|----------------|----------------|
| Cribado automático completo | Al crear / Rehacer cribado |
| Progreso en tiempo real | Barra en el detalle |
| Cribado por parte | Tarjeta de la parte |
| Confirmar / descartar señales | Lista de señales |
| Señal manual | Registrar señal manual |
| Scoring 0–100 y nivel | Hero del caso |
| DDC (simplificada / estándar / EDD) | Sección de compliance |

## Compliance regulatorio

| Funcionalidad | Dónde en la app |
|----------------|----------------|
| Verificación de identidad | Sección amarilla / parte |
| SAR a la UIF | Modal Comunicar a la UIF |
| Congelación BdP | Automático + registro manual |
| Origen de los fondos (EDD) | Sección de compliance |
| Segundo aprobador (EDD) | Modal Aprobar |

## Informes y documentos

| Funcionalidad | Dónde en la app |
|----------------|----------------|
| Informe narrativo KYC | Ver informe |
| Exportar PDF | Botón PDF |
| Carga y extracción | Enviar documento |
| Explainability RGPD Art. 22 | Sección en el informe |

## Leyenda de estados (integraciones)

- **Funcional** — disponible en su instalación.
- **Contingencia manual** — use los campos de registro manual cuando falle la API externa.
- **Administrador** — requiere el perfil Admin o soporte de TI.
