# Features by business area

Summary of the platform’s capabilities for the analyst’s day-to-day work. For the complete inventory with IDs and legal basis, see your institution’s staging documentation.

## Case management

| Feature | Where in the app |
|---------|------------------|
| Open case with PAC validation | New case |
| List and filter cases | KYC cases |
| Approve / reject / review | Case details |
| Assignment and periodic review | Automatic after approval |

## Entities and UBO

| Feature | Where in the app |
|---------|------------------|
| GLEIF resolution / corporate data | Case details (company card) |
| Interactive UBO graph | Details → UBO graph |
| Add party manually | Details → Add party |
| Report RCBE discrepancy | Party identity panel |

## Screening and risk

| Feature | Where in the app |
|---------|------------------|
| Full automatic screening | On creation / Rerun screening |
| Real-time progress | Bar in the details |
| Screening by party | Party card |
| Confirm / dismiss signals | Signals list |
| Manual signal | Record manual signal |
| Score 0–100 and level | Case hero |
| CDD (simplified / standard / EDD) | Compliance section |

## Regulatory compliance

| Feature | Where in the app |
|---------|------------------|
| Identity verification | Yellow section / party |
| SAR to UIF | Report to UIF modal |
| BdP freezing | Automatic + manual record |
| Source of funds (EDD) | Compliance section |
| Second approver (EDD) | Approve modal |

## Reports and documents

| Feature | Where in the app |
|---------|------------------|
| Narrative KYC report | View report |
| Export PDF | PDF button |
| Upload and extraction | Upload document |
| GDPR Art. 22 explainability | Section in the report |

## Status legend (integrations)

- **Functional** — available in your installation.
- **Manual contingency** — use the manual-record fields when the external API fails.
- **Administrator** — requires the Admin role or IT support.
