# Manual online (português)

Conteúdo curado para o centro de ajuda em `/help` na aplicação KYC.

- **Público:** analistas e supervisores de compliance.
- **Idioma:** português (espelho da pasta pai `help-online/`).
- Outros idiomas: [`../en/`](../en/), [`../es/`](../es/).

Para alterar o manual, edite os ficheiros numerados `01-` a `08-` e sincronize também a pasta pai `help-online/` (fonte canónica em português).
